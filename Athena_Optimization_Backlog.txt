COMPLETED / RESOLVED
================================================================================

[VOICE-001] GPU Acceleration for Faster-Whisper
- Status: COMPLETED
- Current: CUDA + float16 (config STT_DEVICE / STT_COMPUTE_TYPE)
- Fallback: CPU int8 if CUDA libs fail
- Notes: nvidia-cublas-cu12 + nvidia-cudnn-cu12 installed; PATH helper in
  voice/cuda_path.py. Benchmark: ~6x faster steady-state on RTX 4070.

[VOICE-004] Conversation vs Action Routing
- Status: COMPLETED (initial + Athena updates)
- Current: brain/intent_router.py (chat vs action)
- Future: Confidence scoring and multi-intent handling still open
  (see VOICE-004b below)

[VOICE-006] Faster-Whisper Model
- Status: COMPLETED (using "small")
- Current: STT_MODEL_SIZE = "small" in config
- Future: optional "medium" if accuracy needs improve (VRAM tradeoff)

[VOICE-007] Wake Word Detection
- Status: COMPLETED (Athena)
- Current wake phrase: "Hey Athena" (also hi/okay/ok athena)
- Backend: Whisper STT wake loop by default
- Optional: voice/models/hey_athena.onnx (OpenWakeWord) if trained later
- Old "Hey Jarvis" OpenWakeWord fallback removed by design

[VOICE-008-THRESH] Wake Word Threshold Tuning
- Status: PARTIALLY ADDRESSED
- Current ONNX threshold (if custom model used): 0.85
- STT wake uses phrase match instead of score threshold
- Future: tune STT false positives / listen window

[TTS-001 / TTS-002] Piper TTS
- Status: COMPLETED
- Current: Piper (en_US-lessac-medium)
- pyttsx3 abandoned (unstable on Python 3.12)

[TTS-002-PIPER] Migration to Piper
- Status: COMPLETED
- Result: Reliable offline TTS

[SYS-001] Sleep Command Uses Hibernate
- Status: Resolved / By Design
- System lacks S3 Sleep; sleep_pc() uses available low-power path
- Future: separate sleep_pc() / hibernate_pc() with capability detection

[AGENT-001] Multi-Step Task Planner
- Status: COMPLETED
- Current: brain/planner.py + executor/plan_executor.py
- Wired in main.py for action intents
- Supports {{step_N}} intermediate results

[AI-001] Conversation Memory
- Status: COMPLETED (short-term + summaries)
- Current: memory/short_term.py + memory/summarizer.py
- Chat prompts include recent context

[GUI-001] GUI Automation Safety (initial)
- Status: PARTIALLY COMPLETED
