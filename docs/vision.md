# Athena Vision / Screen

On-demand capture only — no continuous screenshots.

## Tools

- `take_screenshot` / `read_screen` (OCR)
- `find_on_screen` — locate text + coordinates
- `click_text` (`match_index`) / `click_at`
- `type_text` / `press_key` / `scroll_screen`

Medium-risk UI actions require confirmation by default.

## Modules

- `vision/screenshot.py`
- `vision/ocr.py`
- `vision/ui_automation.py`
